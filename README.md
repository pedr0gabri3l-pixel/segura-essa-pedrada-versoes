# 🪨 Segura Essa Pedrada! (versões)

Este repositório guarda as **versões prontas** do jogo para o launcher baixar.
O código do jogo fica no repositório `segura-essa-pedrada` (privado).

## ▶️ Como jogar

1. Baixe o launcher: **[SeguraEssaPedradaLauncher.zip](https://github.com/pedr0gabri3l-pixel/segura-essa-pedrada-versoes/raw/main/launcher/SeguraEssaPedradaLauncher.zip)**
2. Clique com o botão direito no `.zip` → **Extrair tudo...**
3. Abra a pasta e dê dois cliques em **`SeguraEssaPedradaLauncher.exe`** (deixe ele junto com os outros arquivos da pasta).
4. Se o Windows mostrar "O Windows protegeu o computador", clique em **Mais informações → Executar assim mesmo**. Esse aviso aparece porque o programa é novo e não tem assinatura digital.
5. O launcher baixa a versão mais nova sozinho. Depois é só clicar em **Jogar**.

- O jogo é instalado em `%LOCALAPPDATA%\SeguraEssaPedrada\Jogo`.
- Precisa do **Microsoft Edge WebView2 Runtime**, que já vem no Windows 10 e 11 atualizados.
- O código-fonte do launcher está no repositório `segura-essa-pedrada`, na pasta `Launcher/`.

## 🚀 Como publicar uma versão nova

No Unity, use o menu **Segura Essa Pedrada → Publicar nova versão...**. As versões aparecem em **Releases**, aqui à direita.
